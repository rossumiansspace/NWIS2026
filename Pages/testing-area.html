Testing checklist

Sample test cases from our QA & Systems Test Log (Annex C, Form C-1):

  • Login — dashboard appears on success
  • Wrong password — a clear error message is shown
  • Add record — new entry is saved correctly
  • Delete record — entry is properly removed
  • Search — the correct results are returned
02

Bug reporting

Every bug is logged on our Bug Report form, with these fields:

  • 01
    Bug #A unique reference number for tracking.
  • 02
    DescriptionWhat went wrong and how to reproduce it.
  • 03
    SeverityRated Low, Medium, or High.
  • 04
    Assigned toThe developer responsible for the fix.
  • 05
    StatusTracked as Open, In Progress, or Fixed.
03

QA process

The stages every project passes through:

  • 01
    Unit testingIndividual functions and components are tested in isolation.
  • 02
    Integration testingCombined modules are tested working together.
  • 03
    User acceptance testingThe client tries the system against real use cases.
  • 04
    Sign-offClient approves and the project proceeds to presentation.
