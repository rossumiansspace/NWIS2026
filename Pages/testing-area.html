Testing checklist

What the QA team verifies before sign-off:

  • All core features work as specified
  • UI displays correctly across common screen sizes
  • Forms validate input and show clear error messages
  • No broken links, missing assets, or console errors
  • Basic load and response-time check performed
02

Bug reporting

How an issue moves from spotted to fixed:

  • 01
    ReportTester logs the issue with steps to reproduce.
  • 02
    TriageTeam lead reviews and assigns priority.
  • 03
    FixDeveloper resolves the issue on a fix branch.
  • 04
    VerifyTester confirms the fix before closing the ticket.
03

QA process

The stages every project passes through:

  • 01
    Unit testingIndividual functions and components are tested in isolation.
  • 02
    Integration testingCombined modules are tested working together.
  • 03
    User acceptance testingThe client tries the system against real use cases.
  • 04
    Sign-offClient approves and the project proceeds to presentation.
